功能特性

Postman 风格布局，为个人与团队打造轻量高效的 API 工作台

目录即集合

选择一个工作目录，目录结构即接口集合结构；一个接口一个 JSON 文件，天然支持 Git 版本管理。

接口测试

发送 GET / POST / PUT / DELETE / PATCH 请求，查看状态、耗时、大小、Headers 与 Body（JSON 语法高亮）。

Mock 服务

一键启动本地 Mock 服务，自动扫描启用 Mock 的接口，支持路径参数、延迟、模板变量与环境变量。

演示接口

内置演示 API 集合（用户管理 / 订单管理），开箱即用，快速体验全部功能。

一键导出

导出 Postman Collection、OpenAPI 3.0 或 Docsify 文档站点，方便共享与发布。

代码生成

一键生成 20+ 种语言 / 框架的请求代码：curl、JavaScript、Python、Java、Go、Rust……

全局环境变量

开发 / 测试 / 生产多环境一键切换，{{变量名}} 自动替换到 URL、Headers、Query、Body 与 Mock 响应。

请求历史

自动记录历史请求，随时回看、一键回填重发，调试效率翻倍。

多格式导入

支持 Postman Collection、OpenAPI (Swagger) 协议、Markdown 文档导入，接口与集合变量一键迁移。

版本管理

接口可保存多个版本，左右对比差异，随时回退到任意历史版本。

统计

分组 / 工作区维度统计接口数、Mock 启用数与请求方法分布，一目了然。

灵活设置

丰富的设置项（工作区、代码生成、导出格式等），打造个性化工作环境。

对象管理

分组 + 对象管理数据结构：属性配置（类型 / 引用对象 / Mock 值 / 描述），支持 JSON 与 SQL 建表语句导入，一键生成多语言代码与 MySQL 建表语句。

数据生成

按对象属性批量生成测试数据（JSON / SQL / CSV），自定义表名与记录数；生成记录展示耗时与文件大小，可一键重新生成。

多协议接口

新建接口支持 HTTP / WebSocket / Socket.IO / GraphQL 四种协议，一套工作区统一管理。

目录结构约定

分组即目录，接口即文件 —— 工作区本身就是可读的文档

workspace/
├── __info.json          # 根目录描述（集合信息）
├── __envs.json          # 全局环境变量（可选）
├── 用户管理/             # 分组 = 目录
│   ├── __info.json      # 分组描述
│   ├── 获取用户信息.json  # 一个接口 = 一个 JSON 文件
│   └── 创建用户.json
└── 订单管理/
    ├── __info.json
    └── 获取订单列表.json

Mock 模板变量：{{path.id}} 路径参数、{{query.page}} Query 参数、{{method}}、{{path}}、{{变量名}} 全局环境变量。
